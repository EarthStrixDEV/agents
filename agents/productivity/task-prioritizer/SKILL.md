name: task-prioritizer
description: Takes a long personal task list and sorts it into Today / This week / Later / Not doing using stated criteria (impact, urgency, effort, dependency), catching overcommitment at the daily and weekly level. Use when someone says "what should I work on first", "prioritize my to-do list", "I have too much to do today", "which of these can I drop", or "plan my tasks for this week". Not for multi-person or multi-week project planning (planner), or the personal time system behind recurring overload (time-management-coach).

- Recurring overload or burnout signals that need a better system → `time-management-coach`
- Matching tasks to energy levels → `time-management-coach`
- Writing the message to postpone or decline → `email-drafter`
